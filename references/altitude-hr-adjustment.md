# Altitude Heart-Rate Adjustment

At altitude, perceived effort and heart rate can diverge from sea-level
patterns. Treat these as rough coaching heuristics:

| Altitude | Guidance |
|---:|---|
| under 3,000 ft | Normal zones |
| 3,000-5,000 ft | Expect effort to feel harder |
| 5,000-7,000 ft | Run by effort; pace may slow materially |
| 7,000+ ft | Be conservative; avoid forcing workout splits |

Do not rewrite the athlete's zones permanently based on a single trip. Add a
memory note and compare like with like.

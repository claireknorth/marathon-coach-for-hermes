# Injury Protocol Template

This is a coaching safety template, not medical advice. The athlete should rely
on a clinician for diagnosis and return-to-running clearance.

## Pain Gate

- Pain 0-2/10 that does not change gait: continue cautiously.
- Pain 3+/10, sharp pain, instability, catching, or altered gait: stop.
- Pain that worsens during a run: stop and switch to recovery guidance.
- Pain that lingers or escalates after training: reduce load and seek clinician input.

## Return-to-Running Pattern

| Step | Criteria | Session |
|---|---|---|
| Walk baseline | Pain-free daily walking | No running yet |
| Test run | Cleared and pain-free walking | 10-20 minutes easy |
| Rebuild | Test run tolerated | Add small increments every 2-3 pain-free runs |
| Quality | Several pain-free easy runs | Reintroduce intensity cautiously |
| Full plan | Durable, symptom-free running | Resume plan with monitoring |

## Cross-Training

Bike, swim, elliptical, or walking can preserve aerobic fitness when running is
not appropriate. Match intensity to symptoms and clinician guidance.

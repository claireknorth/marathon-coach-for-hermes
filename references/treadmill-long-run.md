# Treadmill Long Run

Use treadmill mode when weather, safety, or injury constraints make outdoor
running a poor choice.

## Pace To MPH

| Pace | MPH |
|---|---:|
| 12:00/mi | 5.0 |
| 11:00/mi | 5.5 |
| 10:00/mi | 6.0 |
| 9:30/mi | 6.3 |
| 9:00/mi | 6.7 |
| 8:30/mi | 7.1 |
| 8:00/mi | 7.5 |

Use 1% incline as the default outdoor-equivalent setting. For long runs, break
the session into small mental chunks and practice fueling exactly as planned for
race day.

# Training Playbook Template

Use this file to store stable training knowledge for the athlete. Keep live,
changing state in `coach-memory.md`; keep reusable rules here.

## Training Phases

| Phase | Weeks | Goal | Notes |
|---|---:|---|---|
| Base | 1-4 | Build consistency | Mostly easy mileage |
| Build | 5-12 | Add volume and quality | Watch fatigue and HR drift |
| Peak | 13-17 | Long-run specificity | Practice race fueling |
| Taper | 18-20 | Absorb fitness | Reduce volume, keep rhythm |

## Effort Rules

- Easy runs should stay in the athlete's aerobic zone.
- Long runs are aerobic unless the plan explicitly prescribes quality.
- Quality sessions earn recovery.
- In heat or humidity, run by effort and HR instead of target pace.

## Fueling Defaults

| Session | Fuel |
|---|---|
| Under 60-75 minutes | Usually no calories needed in mild weather |
| 75-90+ minutes | 30-60g carbohydrate per hour |
| Long run | Practice race fueling and hydration |
| Hot/humid run | Add fluids and sodium |

## Race-Specific Notes

Add course notes, hills, aid stations, travel plans, and race-week preferences.

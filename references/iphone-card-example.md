# Mobile Card Example

Use compact text that survives mobile messaging apps:

```text
LONG Monday, September 7 - Week 12/20 - Marathon
Today: Long run (12 mi easy)
Weather (Home): 68F feels 69F - dew pt 61F (sticky) - rain 20% - wind 8 mph
Time: Best window 7:30-9:30 AM - lowest dew point
Pace: Stay aerobic; ignore pace if HR drifts
Fuel: Gel every 35-45 min plus fluids
```

Avoid wide tables in delivered messages. Use tables in analysis only when the
athlete specifically asks for raw data.
